# VoltaNode — Money-Making Roadmap

## Top 5 — do these first
1. **Full-quantity exits on trend flips** — make any directional-flip SELL size to the full held quantity, not an equity-% notional, fixing the largest realized-PnL leak across all five strategies at one chokepoint (`strategies/base.py:306-307`; downstream `momentum.py:161`, `macd.py:144`, `mean_reversion.py:159`, `bband_rsi.py:183`, `swing_high_to_sky.py:197`).
2. **Fix the daily-loss kill switch unit mismatch** — convert realized `daily_pnl` (dollars) to a fraction of equity before comparing to `max_daily_loss_pct`, restoring the primary capital circuit-breaker that today trips at a $5 loss or never (`safety/limits.py:227`, `bot/engine.py:1330-1332`; test in `tests/test_safety_equity.py`).
3. **Move broker I/O off the event loop + add a reconciliation loop** — wrap `on_tick` broker calls in `asyncio.to_thread`, `asyncio.gather` per-symbol fetches, and diff broker fills/positions into local state every cycle, killing both the latency "wedge" and the zero-fill position desync (`api/main.py:307-323`, `bot/engine.py:838-846`, `brokers/alpaca.py:282-294`).
4. **Honest fees/slippage + cost-aware entry gate** — book real Alpaca crypto fees, replace flat-bps slippage with `half_spread + k·σ·sqrt(Q/ADV) + fee_bps`, and reject any BUY where `expected_alpha_bps < cost_bps·margin`, so you stop deploying configs that are secretly net-negative (`brokers/alpaca.py:276-277`, `bot/orders.py:195-257`, `strategies/base.py`).
5. **CPCV + Deflated Sharpe as the hard paper→live promotion gate** — block `apply-hyperopt` and any go-live until a config clears purged combinatorial CV with DSR>0, the discipline that prevents shipping a curve-fit edge with real capital (`hyperopt/engine.py:165-199`, `api/routes/strategies.py:1006`, `backtest/engine.py`).

## Flip-to-live readiness gate
All must pass before any real-money flip:
- **Exits flatten fully** — verified test that a directional-flip SELL on an oversized position closes the entire held quantity (`tests/` covering `base.py:306-307`).
- **Daily-loss breaker correct** — unit test proving the breaker trips at `max_daily_loss_pct` of equity (not dollars) and includes unrealized PnL (`tests/test_safety_equity.py`).
- **Drawdown gate actually halts** — soft/hard equity-curve bands fed by `compute_portfolio_equity` measurably block orders in `SafetyValidator.validate_order` (not `pass`).
- **No event-loop blocking + reconciliation proven** — broker I/O off the loop; a forced zero-fill/pending order reconciles local↔broker state within one cycle; no double-buy on the next tick.
- **Costs booked honestly** — live Alpaca fills carry real crypto fee + spread; paper slippage is spread/vol-conditional; numpy RNG seeded; a sample strategy that was "profitable" at free fills is re-checked net of cost.
- **Cost-aware gate live** — BUYs that don't clear `cost_bps·margin` are rejected; mean-reversion defaults reverted to 30/70.
- **Validation gate enforced** — `apply-hyperopt`/promotion blocked unless the config clears CPCV (purge+embargo) with DSR>0 over all trials; same-bar look-ahead fill removed; entries excluded from win-rate denominators.
- **Data freshness enforced** — crypto runs on true intraday klines; every tick/bar carries `as_of`; signals on bars older than N×tick_interval are flagged/rejected; no synthetic-data fallback can silently substitute.
- **Sizing in risk units** — live sizing is vol-targeted and capped at `max_position_size_pct=20`; no hardcoded $1000 notional paths remain; correlation/cluster cap applied at auto-deploy.
- **Measured shadow run** — small-capital live pilot run in parallel with paper for N days; per-trade decision→paper→live implementation shortfall logged and within the cost model's tolerance before scaling capital.
